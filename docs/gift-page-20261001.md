# Mon futur chez-moi — 1 octobre 2026

Route /cadeau, entrée accueil et Mon compte. Quatre réponses choisissent les images et un ou deux des six guides existants. La planche se télécharge en PNG ; les guides sont des PDF statiques, également fondés sur du contenu déjà public.

Récupération : inscription particulier réduite à email, mot de passe, CGU ; confirmation email via le dispositif Supabase existant. Le projet est inclus dans les métadonnées d'inscription pour le retrouver après confirmation sur un autre appareil. Ces métadonnées servent uniquement au contenu, jamais aux autorisations. Un compte existant peut se connecter. Les réponses et les simulations enregistrées sont conservées dans gift_projects, une ligne par compte, avec RLS propriétaire et suppression en cascade du compte. Pas d'inscription newsletter automatique ni d'envoi supplémentaire du cadeau par email : téléchargement depuis l'espace.

La migration gift_projects a été appliquée au projet existant et les droits relus : RLS activée, quatre politiques, aucun accès anonyme. Aucun nouvel avertissement de sécurité ne concerne cette table ; les avertissements existants sur d'autres objets n'ont pas été modifiés dans ce changement.

Vérifications : 159 tests existants ; 36 tests ciblés comprenant les trois nouveaux tests de correspondance guides, API et isolation PostgreSQL. Parcours Chromium mobile 390 px avec API simulée : questionnaire terrain, inscription courte, retour de confirmation validé par /auth/user, sauvegarde, export PNG, liens vers deux PDF, reprise des montants après rechargement, absence de débordement horizontal. Aucun email réel n'a été envoyé pendant ce test. Les routes et fichiers publics doivent être contrôlés après déploiement.
